# 計算エンジンの仕様

`app/engine.js` の `compute(state)` が、入力から年ごとのキャッシュフロー表を作る。
Excel「ライフプラン表 ver.1.79」の CF表シートの数式を、行ごとに対応させて実装している。
金額の単位は万円、率は％で受け取る。

## 期間

開始年から、家族１の年齢（その年 − 生年）が終了年齢に達する年までの各年。
サンプル（家族１が1991年生まれ、90歳まで）では 2026〜2081年の56年。

## 行の型

入力の行は4つの型のどれかで、その年の金額の出し方が決まっている。

| 型 | その年の金額 | 使っている項目 |
|---|---|---|
| 変更型 | その年以前で一番新しい行の金額 | 住宅費、保険料、自動車の維持費、公的年金、その他の経常支出 |
| 一時型 | その年の行の金額 | 退職一時金・その他一時収入、住宅費一時金、その他の一時支出 |
| 期間型 | 開始年〜終了年に入る行の年額 | 企業年金、個人年金・保険、投資の積立、投資の現金化 |
| 周期型 | 開始年から N 年ごと、家族１が指定年齢になるまで | 自動車の購入費 |

給与と基本生活費は変更型に上昇率が付いた特別な型（下記）。

## 各行の計算（CF表シートとの対応）

| CF表の行 | 計算 |
|---|---|
| 11〜13 給与 | 変更年はその行の手取額。それ以外は 前年 ×（1＋直近の変更行の上昇率）。退職年齢に達した年から0 |
| 14 退職金・年金・その他 | 一時収入＋企業年金＋個人年金＋公的年金 |
| 15〜16 投資の現金化 | 予定額が前年末のその資産の残高以下ならその額、超えるならその年は0 |
| 19 基本生活費 | 変更年は 入力額 ×（1＋物価上昇率）^（その年 − 開始年）。それ以外は 前年 ×（1＋物価上昇率） |
| 20 住宅費 | 変更型＋一時金 |
| 21 教育費 | 子供ごとに、在学期間に入る段の年額の合計 |
| 22 保険料 | 変更型 |
| 23 自動車 | 維持費（変更型）＋購入費（周期型） |
| 24 その他 | 経常支出（変更型）＋一時支出 |
| 25〜26 投資の積立 | 予定額が「前年末の普通預金 − その年すでに積み立てた額」以下ならその額、超えるならその年は0 |
| 28 年間収支 | 収入計 − 支出計（現金化は収入、積立は支出に含む） |
| 31 普通預金等 | （前年末 ＋ 年間収支）×（1 ＋ 利率 × 0.8） |
| 32〜33 投資資産 | （前年末 − 現金化）×（1 ＋ 想定利回り ×（1 − 税率））＋ 積立 |

教育費の在学年は生年月日から決まる。4月1日以前生まれ（早生まれ）は1年早い。
各段の金額は単価表（`EDU_UNIT`、入力シート T138:V153 と同じ）から引く。

## Excelでの確認状況

`npm test` で照合している。

| 項目 | 状態 |
|---|---|
| 教育費・住宅費・自動車・退職金と年金の年合計（入力シートの集計行） | Excelの値と一致 |
| 手取額計算（年収600万円） | 一致（社会保険料93、税45.45） |
| CF表の全行（給与・生活費・収支・各残高） | **未照合**。Excelの計算済みの値が必要（下記） |

CF表全行の照合は、Excelファイルから値を取り出してから行う。

```
python3 -I tools/extract_excel_fixture.py <ライフプラン表.xlsx>   # test/fixtures/excel-cf.json を作る
npm test
```

Excel本体は公開リポジトリに入れない（`.gitignore` 済み）。取り出すのは計算結果の数値だけ。

## Excelから解釈して決めたこと

Excelの数式で意図が一つに決まらなかった箇所、またはアプリとして意図的に変えた箇所。

1. **CF表の初年度の列（D列）の数式は読み取っていない。** 2年目以降と同じ式で、前年の値として「前年末の金融資産」を使うと仮定した。全行照合で確かめる。
2. **給与の、最初の変更行より前の年は0。** Excelの数式は外側の ISERROR の分岐が読み切れていない。
3. **同じ年の変更行は合算する。** Excelは VLOOKUP で先頭の1行だけを拾うため、注意書きで「同じ年は1行にまとめる」よう求めている。アプリでは合算したうえで、重複を知らせて1行にまとめるボタンを出す。
4. **「◯歳まで働く」は、その年齢に達した年から給与を0にする。** Excelのサンプルは家族１の給与を「生年＋65年」に0にしており、公的年金もその年から始まる。これと同じ解釈。
5. **普通預金等の利率を入力できるようにした。** Excelでは入力シートになく、CF表シートの C31 に直接置かれている（0）。初期値は0なので結果は変わらない。
6. **教育費の在学年を書き換えた段は、生年月日を後から変えても動かない。** 書き換えていない段は生年月日に追従する。
7. **自動車の購入費を回ごとに変えた金額は、年で覚えている。** 開始年や周期を変えて、その年が購入年でなくなった場合、その上書きは使われない。
8. **手取額計算の課税所得は万円未満を切り捨てる。** シートの課税所得 270・272 と合わせるため。
