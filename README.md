# Handoff: ライフプラン入力画面（Flutter / Android）

## Overview
Excelの「ライフプラン表」をベースにした、家計・資産シミュレーションアプリの入力UI。約400項目という多い入力項目数を、素早く目的の項目へ到達できる形にまとめている。

## About the Design Files
このバンドルのHTMLファイルは **デザインリファレンス** です。実装用のコードではなく、見た目と挙動の仕様を示すプロトタイプです。実際の実装は、対象コードベース（本件はFlutter / Android）の環境・パターンに沿って作り直してください。

## Fidelity
**Hi-fi**：配色・タイポグラフィ・レイアウト・インタラクションは最終仕様に近い状態です。ピクセル単位で再現してください。ただし色は「ベージュ×テラコッタ系」の想定で作成したもので、指定確定ではありません（下記Design Tokens参照）。

## Screens / Views

メインの実装対象は `Life Plan Input.dc.html`（幅412pxのAndroid想定・1画面・縦スクロール）。

### 画面構成（上から）
1. **アプリバー** 高さ56px、背景は `--color-bg`。タイトル「ライフプラン」（Zen Maru Gothic, 19px, weight 900）。
2. **サマリーバー**（`position: sticky; top: 0`、高さ72px、スクロールしても画面上部に固定）
   - 通常時：左に「終了時点の金融資産」（12px, 500, グレー）、右に金額「1,240万円」（19px, 900）。下にスパークライン（軸・目盛りなし、SVG viewBox 340×32）。
   - 警告時：バー背景が `--color-accent-100`（淡い赤〜テラコッタ）に変化。「⚠ 52歳で預金が不足します」＋右に「−180万円」。終了時点金額は非表示。スパークラインの色も accent-800 系に変化。
   - タップで全画面グラフ遷移（本バンドルではプレースホルダーの `onClick` のみ実装、遷移先グラフ画面は別途要実装）。
3. **セクション目次バー**（`position: sticky; top: 72px`、スクロールしても固定）
   - ［基本］［収入］［支出］［投資］の4タブ。ピル型、アクティブ時は `--color-accent` 塗り＋白文字。
   - タップは画面切替ではなく、本文の該当セクションへスクロールジャンプ（`scrollTop` を対象要素の `offsetTop - 118px` に設定）。
   - スクロールに応じてどのタブがアクティブかも自動更新（各セクション先頭が `offsetTop - 140px` を超えたら切り替え）。
4. **本文**：1本の縦スクロール、セクションが「基本→収入→支出→投資」の順で並ぶ。

### セクション「基本」
- **シミュレーション終了年齢**：数値入力1つ＋「歳まで」。カード（白背景、`--radius-lg`、`--shadow-sm`）。
- **前年末の金融資産**：普通預金等／NISA／iDeCo の3行。各行は「ラベル＋右寄せ数値入力＋万円」。行間に薄い区切り線。
- **家族構成**（最大4人）：氏名（下線付きテキスト入力）＋続柄タグ（丸ピル、accent-2系）を1段目、生年月日＋年齢（グレー小文字、自動算出）を2段目。

### セクション「収入」「支出」「投資」共通：行エディタ（最重要コンポーネント）
繰り返し使われる中核パーツ。厳密に以下の仕様：
- 1行は2段組み
  - 1段目：年の数値入力（下線スタイル、右寄せ、18px, 700）＋「年から」（lump型は「年に」）＋右端に削除アイコン（Material Symbols `delete`, 20px, グレー）
  - 2段目：金額の数値入力＋「万円」＋（給与系グループのみ）上昇率の数値入力＋「%」
- 年入力欄の下に年齢参考表示（グレー10.5px）：例「夫 60歳 ・ 妻 60歳」（`夫の生年1991・妻の生年1991`から自動算出）
- グループ末尾に「＋ 追加」1つのみ（Material Symbols `add` + テキスト）
- 空行は表示しない。0行のときは「＋追加」のみ
- 各リスト最大5行（`canAdd` が false になったら「＋追加」を非表示）

収入グループ：給与（夫）／給与（妻）／給与（その他）／退職一時金（lump型）／公的年金
支出グループ：基本生活費／住宅費／教育費／保険料／自動車関連費／その他支出（lump型）
投資グループ：NISA積立／iDeCo積立

## Interactions & Behavior
- 目次タップ → 該当セクションへスムーズスクロール（実装ではアニメーションなし、即時ジャンプ。要件次第でイージングを追加してよい）
- スクロール → 目次のアクティブ状態が自動更新
- 各入力欄 `onChange` で即時に状態更新（バリデーションは未実装。数値以外の入力時は0にフォールバックしている簡易実装）
- 行の削除アイコンタップ → その行を配列から除去
- 「＋追加」タップ → 新規行を末尾に追加（初期値：年は直前行+5、金額0）
- 5行に達したグループは追加ボタンが消える

## State Management
- 家族構成配列（id, name, relation, birth）
- 資産オブジェクト（deposit, nisa, ideco）
- 各グループのリスト（id, year, amount, growth?）
- アクティブな目次タブ（スクロール位置から自動導出）
- シミュレーション終了年齢（単一数値）

年齢表示は「対象年 − 生年」で都度算出。世帯主・配偶者の生年をグローバルに保持している前提（本実装では1991年固定）。

## Design Tokens
Organic design system（`_ds/organic-*/styles.css`）のCSS変数をそのまま使用：
- `--color-bg` #f5ead8、`--color-text` #201e1d
- `--color-accent` #c67139（テラコッタ）、ランプ100〜900
- `--color-accent-2` #7a8a5e（セージ）、ランプ100〜900
- `--color-neutral-100`〜`900`
- `--font-heading`: Caprasimo、`--font-body`: Figtree（本画面は和文のため上書きで **Zen Maru Gothic** を指定）
- `--radius-lg`（カード角丸）、`--shadow-sm`（カード影）
- アイコン：**Material Symbols Rounded**（絵文字不使用、weight 500, FILL 0, opsz 24）

配色が「ベージュ×テラコッタ」で確定か、「ピーチ×ミント」に変更するかは要確認。
