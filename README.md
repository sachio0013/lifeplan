# ライフプラン

Excel「ライフプラン表」を元にした、家計・資産シミュレーションのスマホ向けWebアプリ。
入力画面、キャッシュフロー（CF）表の画面、プランの比較画面がある。

主な機能：

- **給与明細**：Excel ver.1.80の「給与シート」と同じく、毎月の給与明細と賞与明細（夏・冬）の支給（基本給〜通勤費）と控除（健康保険〜財形・DC等）を家族１・家族２の2人分記録し、1年分の手取りを積み上げる。手取り＝支給合計−社会保険料−所得税・住民税（財形・DC等と通勤費は含む）。前の月の明細を写せ、住民税（6月）・社会保険料（9月の見直し）・介護保険料のはじまり・残業代の増減を「ふりかえり」で説明する。振込額と財形・DC等は家計簿のその月へ、年間の手取りはプランの給与へ入れられる（記録が途中なら平均×12＋賞与で見積もる）。Excelの記入例と計算済みの値で照合（`test/book.test.mjs`）
- **家計簿（年間収支）**：Excelの「家計簿（年間収支）」シートと同じく、1年を1枚にまとめる。月に1回、項目ごとの合計（円）を入れるだけ。項目は区分（1 基本生活費〜6 積立投資）を持ち、区分はライフプランの入力項目に対応する。決済手段別・区分別の集計、手取収入と備考、収支と残高、口座残高との差額（0なら記録に漏れなし）、投資資産の前年末と今年末を出す。記録した月の平均×12でライフプランに反映でき、記録した月数と残高の一致から「信頼度」を示す。毎月の「ふりかえり」（いつもとの違い、貯蓄・投資に回せた割合、続けた月数）も出す。計算は `app/book.js`、Excelの記入例と計算済みの値で照合（`test/book.test.mjs`）
- **データを外に送らない**：入力（プラン・家計簿）はすべて端末のブラウザの中だけに保存し、通信しない。登録も口座連携もいらない
- **表紙**：はじめて開くと、できることと3つの手順を見せ、「家族のかたち」「住まい」「気になること（住宅購入・教育費・老後・積立投資・働き方・節約）」を選んでもらう。選んだ家族のかたちに合わせた参考値（`app/sample.js` の `REF`。書き換える前提の目安の例で、統計の平均ではない）が入った状態でかんたん入力が始まり、参考値のままの欄には印が付く。表紙はプランの一覧からいつでも開ける。かんたん入力で自分のプランを作ると、書き換えていない記入例は一覧から外れる（表紙からいつでも開ける）
- **FPからの次の一歩**：表紙で選んだ気になることごとに、やってみるとよいことを未来の表（グラフの下）と入力画面の上に出す。ボタン1つで「家を買った場合」「積立なし」「1割節約」「働き方を変える」のプランを作り、比較画面で並べる。家を買う場合は、今の住まいのプランを複製した「（家を買う）」のプラン（2年後に4,000万円・35年ローン）を作り、「家の値段・ローンを変える」はそのプランの住宅ローンの欄を開く（今の住まいのプランは変えない）
- **足りなくならないためには**：普通預金等がマイナスになるプランでは、未来の表に「投資資産を自動で現金化すれば足りるか」「基本生活費を月いくら減らせば足りるか」を計算して出し、ボタン1つで試せる（減らしたプランは比較画面で並べる）。ほかの見直し先（働き方・年金・住宅費・教育費）へも案内する。保障タブでは、必要保障額のうち万一がなくても足りない分を分けて示す
- **「？」の説明**：入力画面の各欄の見出しの「？」で、入れ方の目安や注意点（FPのひとこと）を開く
- **かんたん入力**：必須の項目だけを6ステップで聞き、新しいプランを作る。言葉は「家計の中心の人」「今の貯金」など、むずかしい言葉を避ける。給与は「毎月の手取り＋ボーナス（1年の合計）」、支出は「1か月の額」で聞いて年額にし（「1年で◯万円」を添える）、円で入れてしまった額（30万円を「300000」など）は「万円で」と知らせる。開始年・利回り・昇給率・物価上昇率など、ふつうはそのままでよい項目は「くわしい設定」にたたむ。年金は自動で計算した額（月あたりも）だけを見せ、内訳はたたむ。教育費の進路は大学（私立文系）まで（大学院は「進学しない」）
- **入力の確認**：計算に使われない・結果がおかしくなる入力（期間の逆転、期間外の行、もう過ぎた退職年齢など）を欄の下で知らせ、件数を上部に出す
- **変化の表示**：入力を変えるたびに、終了時点の金融資産がいくら増減したかをサマリーバーに数秒出す
- **手取りの計算**：会社員向けに、年収（額面）・配偶者の扶養と年収・扶養する子供や親から、手取りの概算を出して給与の1行目に入れる。Excelの手取額計算シート（2025年4月〜）と同じ式で、子供や親の年齢は家族構成の生年月日から自動で判定する。健康保険の種類（協会けんぽ・健康保険組合）と年齢で社会保険料を見積もったり、源泉徴収票の実額を使ったりでき、去年の年収を入れると住民税をそれで計算する（住民税は前年の所得で決まるため）。源泉徴収票が手元にあれば、欄の金額（支払金額・源泉徴収税額・社会保険料等の金額など）をそのまま円で入れて、実際の金額から手取りを出せる。手取りは「額面−社会保険料−所得税−住民税＋通勤手当」と定め、生命保険料や財形など任意の天引きは手取りに含める（画面に一覧表あり。家計簿では決済手段「給与天引き」で収入にも自動で足す）
- **Excelに書き出す**：未来の表から、CF表とグラフ（金融資産残高の推移・収入と支出）を色付きの .xlsx で保存する。外部ライブラリを使わず `app/xlsx.js` でファイルを組み立てる（無圧縮のzip、スタイル、Excelの本物のグラフ）。「サマリー」シート（ポイント・家族・グラフ、縦1ページで印刷）と「CF表」シート（行と列の固定、マイナスは赤字、0は「-」、見出しを各ページに印刷）。グラフはCF表のセルを参照するので、表を書き換えるとグラフも変わる。保障タブ（保障サマリー：結果・条件・遺族年金・いつも／もしも／保険で備えた場合のグラフ、もしものCF表、かんたん計算の内訳）と、家計簿の1年の表（まとめ：区分別の積み上げ棒＋収入の折れ線、年間収支の表）も同じように書き出せる
- **現金化の自動調整**：投資タブで「自動で調整する」を選び「保ちたい普通預金等」と「何歳から」を入れると、毎年、普通預金等がその額を下回らないように投資資産の現金化の額を自動で決める（課税口座 → iDeCo → NISAの順）。保てる年齢、10年ごとの平均額、自動調整なしとの比較グラフを表示する。毎年の額は未来の表の「◯◯の現金化」の行に出る
- **保障（必要保障額）**：家計の中心の人に万一のことがあったときの必要保障額を、Excelの「必要保障額」シートと同じ「かんたん計算」と、今のプランから「◯年に亡くなったら」のCF表を作る「CF表で計算」の2通りで出す。遺族年金（2028年改正の有期給付・子の加算）、生活費の割合、団信（住宅費の行に印）、葬儀費用、死亡退職金、加入中の保険を反映し、保険金を入れると足りるかがわかる。もしもの場合をプランとして保存して比べられる
- **DC（会社拠出）の見込額**：Excelの「投資シミュレーション」シートと同じ式（今の残高・会社の掛金・想定利回り・コスト・積み立てる年齢）で、受け取る年齢の見込額を出し、退職一時金の行に入れる。年ごとの表、グラフ、目標額からの逆算（毎年いくら必要か）もある
- **公的年金の見込み**：プランの給与を額面に直し、厚生年金（額面×5.481/1000、上限は2030年から月75万円）と基礎年金を自動で見込んでCF表に使う。役職定年・再雇用の減額もそのまま反映。これまでの分は「かんたん（賃金カーブ）」「1年目の年収」「ねんきん定期便」から選べ、受け取りはじめる年齢（繰上げ・繰下げ）も変えられる。手取りに直して将来の目減り（9割）を掛ける。「自分で入力する」にもできる
- **住宅ローンの試算**：借入額・期間・金利（3段階まで）から返済額と年ごとの返済表を出し、住宅費の行に反映する（Excelの返済表と同じ計算）
- **年／年齢の切り替え**：年の欄を西暦でも年齢でも入れられる（保存は西暦）
- **複数のプランと比較**：条件を変えたプランを保存し、3つまで推移と主な数字を並べる。いちばん上の「くらべると」で、最後に残るお金の差と、お金が足りなくなる年齢の違いを文で示し、それぞれのプランを開くボタンを置く
- **結果をひとことで**：未来の表のいちばん上に「このままだと、夫が77歳になる2069年に、貯金が足りなくなります」「夫が90歳になるまで、お金は足りる見込みです」のように、だれが何歳のときかを名前で示す。グラフの見方も添える
- **入力のしやすさ**：数字の欄はタップすると中身が全部選ばれる（そのまま打てば置き換わる）。全角数字・カンマも可、Enterで次の欄へ。スマホで入力中は上のバーと目次をたたむ。削除や反映のあとは画面下の「元に戻す」で戻せる。年額の支出には月あたりの額を添える
- **バックアップ**：すべてのプランをファイル（またはテキスト）に書き出し、読み込んで戻せる
- **最初からやり直す**：最後の1つのプランも削除でき、削除すると記入例だけの表紙（はじめて開いたときの状態）に戻る（家計簿は残る）。プランの一覧の一番下の「すべて消して最初から」で、プラン・家計簿・給与明細をすべて消せる。どちらも直後なら「元に戻す」で戻せる

```
npm test          # 計算のテスト
npm run build     # dist/ を作る
npm run e2e       # ブラウザで操作するテスト（先に build）
```

入力内容はブラウザの保存領域（localStorage、キー `lifeplan.v2`）に端末ごとに保存される。
形は `{ version: 2, activeId, nextPlanId, plans: [{ id, name, state }], prefs: { yearMode, welcomed }, book: { years: { 'YYYY': 1年分 }, nextId } }`。
1プランだけを保存していた頃のデータ（`lifeplan.v1`）は、開いたときに1つ目のプランとして引き継ぐ。

公開版はファイル保存に Artifact の `downloads` 機能を使うので、公開時に `capabilities: {downloads: true}` を付ける。

# Handoff: ライフプラン入力画面（Flutter / Android）

## Overview
Excelの「ライフプラン表」をベースにした、家計・資産シミュレーションアプリの入力UI。約400項目という多い入力項目数を、素早く目的の項目へ到達できる形にまとめている。

## About the Design Files
このバンドルのHTMLファイルは **デザインリファレンス** です。実装用のコードではなく、見た目と挙動の仕様を示すプロトタイプです。実際の実装は、対象コードベース（本件はFlutter / Android）の環境・パターンに沿って作り直してください。

## Fidelity
**Hi-fi**：配色・タイポグラフィ・レイアウト・インタラクションは最終仕様に近い状態です。ピクセル単位で再現してください。ただし色は「ベージュ×テラコッタ系」の想定で作成したもので、指定確定ではありません（下記Design Tokens参照）。

## Screens / Views

メインの実装対象は `Life Plan Input.dc.html`（幅412pxのAndroid想定・1画面・縦スクロール）。

### 画面構成（上から）
1. **アプリバー** 高さ56px、背景は `--color-bg`。タイトル「ライフプラン」（Zen Maru Gothic, 19px, weight 900）。
2. **サマリーバー**（`position: sticky; top: 0`、高さ72px、スクロールしても画面上部に固定）
   - 通常時：左に「終了時点の金融資産」（12px, 500, グレー）、右に金額「1,240万円」（19px, 900）。下にスパークライン（軸・目盛りなし、SVG viewBox 340×32）。
   - 警告時：バー背景が `--color-accent-100`（淡い赤〜テラコッタ）に変化。「⚠ 52歳で預金が不足します」＋右に「−180万円」。終了時点金額は非表示。スパークラインの色も accent-800 系に変化。
   - タップで全画面グラフ遷移（本バンドルではプレースホルダーの `onClick` のみ実装、遷移先グラフ画面は別途要実装）。
3. **セクション目次バー**（`position: sticky; top: 72px`、スクロールしても固定）
   - ［基本］［収入］［支出］［投資］の4タブ。ピル型、アクティブ時は `--color-accent` 塗り＋白文字。
   - タップは画面切替ではなく、本文の該当セクションへスクロールジャンプ（`scrollTop` を対象要素の `offsetTop - 118px` に設定）。
   - スクロールに応じてどのタブがアクティブかも自動更新（各セクション先頭が `offsetTop - 140px` を超えたら切り替え）。
4. **本文**：1本の縦スクロール、セクションが「基本→収入→支出→投資」の順で並ぶ。

### セクション「基本」
- **シミュレーション終了年齢**：数値入力1つ＋「歳まで」。カード（白背景、`--radius-lg`、`--shadow-sm`）。
- **前年末の金融資産**：普通預金等／NISA／iDeCo の3行。各行は「ラベル＋右寄せ数値入力＋万円」。行間に薄い区切り線。
- **家族構成**（最大4人）：氏名（下線付きテキスト入力）＋続柄タグ（丸ピル、accent-2系）を1段目、生年月日＋年齢（グレー小文字、自動算出）を2段目。

### セクション「収入」「支出」「投資」共通：行エディタ（最重要コンポーネント）
繰り返し使われる中核パーツ。厳密に以下の仕様：
- 1行は2段組み
  - 1段目：年の数値入力（下線スタイル、右寄せ、18px, 700）＋「年から」（lump型は「年に」）＋右端に削除アイコン（Material Symbols `delete`, 20px, グレー）
  - 2段目：金額の数値入力＋「万円」＋（給与系グループのみ）上昇率の数値入力＋「%」
- 年入力欄の下に年齢参考表示（グレー10.5px）：例「夫 60歳 ・ 妻 60歳」（`夫の生年1991・妻の生年1991`から自動算出）
- グループ末尾に「＋ 追加」1つのみ（Material Symbols `add` + テキスト）
- 空行は表示しない。0行のときは「＋追加」のみ
- 各リスト最大5行（`canAdd` が false になったら「＋追加」を非表示）

収入グループ：給与（夫）／給与（妻）／給与（その他）／退職一時金（lump型）／公的年金
支出グループ：基本生活費／住宅費／教育費／保険料／自動車関連費／その他支出（lump型）
投資グループ：NISA積立／iDeCo積立

## Interactions & Behavior
- 目次タップ → 該当セクションへスムーズスクロール（実装ではアニメーションなし、即時ジャンプ。要件次第でイージングを追加してよい）
- スクロール → 目次のアクティブ状態が自動更新
- 各入力欄 `onChange` で即時に状態更新（バリデーションは未実装。数値以外の入力時は0にフォールバックしている簡易実装）
- 行の削除アイコンタップ → その行を配列から除去
- 「＋追加」タップ → 新規行を末尾に追加（初期値：年は直前行+5、金額0）
- 5行に達したグループは追加ボタンが消える

## State Management
- 家族構成配列（id, name, relation, birth）
- 資産オブジェクト（deposit, nisa, ideco）
- 各グループのリスト（id, year, amount, growth?）
- アクティブな目次タブ（スクロール位置から自動導出）
- シミュレーション終了年齢（単一数値）

年齢表示は「対象年 − 生年」で都度算出。世帯主・配偶者の生年をグローバルに保持している前提（本実装では1991年固定）。
